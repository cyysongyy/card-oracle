# 🎴 心象牌卡 Card Oracle

線上心理投射牌卡：憑直覺選一張牌，翻開後顯示背後意涵（意象、光明面、陰影面、自我提問）。
純靜態網站，無後端，可直接放上 GitHub Pages。

牌組（共 24 組、735 張，每組至少 30 張（食物牌組 45 張，含台灣道地食物 15 張））：
- 🌿 自然萬象：植物｜動物｜食物｜山水
- 🔮 投射意象：顏色｜形狀｜家屋（房樹人啟發）｜夢境｜天氣｜交通｜物件｜角色（榮格原型）｜情境（主題統覺啟發）｜樂器
- 🧠 心理探索：情緒（Plutchik 情緒輪）｜價值（價值卡片分類）｜優勢（VIA 性格優勢）｜職涯（Holland RIASEC）｜身體｜手勢｜童年（內在小孩）｜童話｜運動｜療癒
- 🎲 綜合（全部混合）

玩法：圖卡先正面朝上 → 憑直覺點選 → 翻到背面看心理意涵。
插圖：內嵌 Twemoji 向量圖（CC-BY 4.0），無需外部圖片檔。

## 最簡單的部署（只傳一個檔案）
`deploy/index.html` 是已把 CSS、JS、全部牌組與插圖打包好的**單一檔案**。只要把它上傳到 repo 根目錄覆蓋 `index.html` 即可。
修改原始碼後，執行 `python build.py` 可重新產生。

## QR Code
部署後打開網站，按「📱 QR Code」即可顯示、下載、列印該網址的 QR（自動以目前網址產生）。

## 部署到 GitHub Pages
1. 新增 repo（例如 `card-oracle`），把本資料夾所有檔案上傳到根目錄。
2. Settings → Pages → Source: `main` / `(root)` → Save。
3. 網址：`https://cyysongyy.github.io/card-oracle/`

## 新增牌組（例如動物）
1. 複製 `data/colors.js` 為新檔（例如 `data/birds.js`），用 `mkDeck(id, 名稱, emoji, 導語, 前綴, rows)` 寫入牌卡。
2. 在 `index.html` 加一行 `<script src="data/birds.js"></script>`（放在 emoji.js 與 app.js 之前），再執行 `python build.py`。分頁與綜合牌組會自動出現。

## 牌卡欄位
mkDeck 每列：`[名稱, 英文, emoji, 色相, 意象, 意涵, 光明面, 陰影面, 自我提問, (選填)背景CSS, (選填)文字色]`

## 聲明
本工具為自我覺察與對話引導之趣味工具，非心理診斷或專業評估。

## 設計依據
心理投射測驗以模糊刺激引出聯想（如墨跡、房樹人繪畫、主題統覺、色彩與形狀聯想）。本工具借用「聯想」概念做自我覺察遊戲，牌義為通俗象徵詮釋，顏色等象徵因文化與個人經驗而異，不具診斷效力。
